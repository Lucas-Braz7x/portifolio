# Experiments — Lab

Itens informais do Lab (spec 07). Um arquivo `.md` ou `.mdx` por experimento.

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| `title` | sim | Título |
| `summary` | sim | Uma linha |
| `url` | não | Link externo (se omitido, só título + linha) |
| `order` | não | Ordenação na lista |

Corpo opcional (nota curta); não usa template de case study.
